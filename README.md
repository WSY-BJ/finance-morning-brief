## 内容能力及真实限制

自动来源新增中国证券网首页的原文文章，同时保留新华社、政府网、证券时报、上海证券报的中文新闻索引。原文采集解析发布者结构化数据、检查北京时间过去 24 小时、校对原文标题，保存获取时间、正文摘要和 SHA-256。索引标题只能作为待核验消息，不冒充已读正文；抓取失败显示缺口。当前没有语言模型接口，也没有新增收费服务。自动脚本不能独立完成多语言翻译、全文事实核验、主题归并或专属因果研究。

`editorial/YYYY-MM-DD.json` 可保存手工中文翻译或正文审核事件。`headline-translation` 只翻译标题；`source-reviewed` 必须附正文证据、抓取时间、具体事实、事件分析、反证、验证方法及公司关系证据。程序校验出处字段，不代表程序已经理解或核实原文。审稿人负责语义正确性。只有正文审核事件可进入利润雷达。

2026-10-09 新增一条已读取上海证券报原文的假期消费研究及利润雷达，讨论固定成本、渠道折扣、库存和现金流；保留七条旧报来源标题的中文翻译；移除无关军事新闻、重复市场综述和缺少新事件的电动车解释稿。没有把翻译提升为事实核验。

## 自动发布

北京时间 05:17、06:43、07:31、08:17 调度；GitHub Actions 的调度可能延迟，无法保证严格 08:00。每日流程：回归测试 → 生成 → 内容/来源校验 → 提交最新与历史 → Pages 部署 → 比对线上报告、当日归档、历史索引和页面资产的完整 SHA-256 → 通知。

同一天复用有效版本，内容不足不触发反复采集和重复通知。代码版本变化或页面内容不一致会重新生成/部署。手动 `Daily finance brief` 默认不通知。只有每日未领取的通知可调用 Server酱；部署失败或内容不一致阻止通知。受理成功只表示接口接受请求，不证明微信实际送达。

唯一现有 Secret：`SERVERCHAN_SENDKEY`。不读取、不打印密钥。保留历史档案；旧版本可从 Git 历史恢复。历史索引不再截断为 120 条。
